Slide Outline
1. Title Slide
Exploring Math, Sacred Geometry, and Art with Code

Subtitle ideas:

“Using AI to make the impossible-looking approachable”
“Not AI slop — AI as a creative coding assistant”
“How math becomes visuals, sound, and interactive art”
Visual: animated geometric pattern, fractal, black hole render, or generative art grid.

2. The Big Idea
Coding used to feel locked behind technical knowledge.

You needed to know:

syntax,
math,
graphics libraries,
physics,
audio processing,
animation loops.
Now AI can help explain and generate those building blocks.

The artist still chooses the direction. AI helps with execution.

3. What Is Creative Coding?
Creative coding is writing code where the goal is expression, not just utility.

Examples:

generative art,
fractals,
music visualizers,
simulations,
interactive installations,
shader art,
procedural worlds,
sacred geometry,
data-driven visuals.
Good line:

“Creative coding is where math stops being homework and starts becoming a paintbrush.”

4. Topic 1: Fractals
Fractals are patterns that repeat at different scales.

Examples:

Mandelbrot set,
Julia sets,
Sierpinski triangle,
fractal trees,
Romanesco broccoli,
coastlines,
snowflakes.
Main point:

Tiny rules can create infinite complexity.

AI accessibility angle:

You can ask AI: “Explain the Mandelbrot set like I’m new to coding.”
Then: “Write me a p5.js sketch that zooms into it.”
Then: “Make the colors feel like a 1980s sci-fi poster.”
Possible demo:

Mandelbrot zoom
Fractal tree with sliders for angle/branch length
Sierpinski triangle generated point-by-point
5. Fractals Slide Talking Point
Fractals are a perfect example of why code art is cool:

A very small equation can generate an image that looks organic, cosmic, or impossible.

This is also where AI is useful. You may not know complex numbers or recursive functions yet, but AI can help you:

understand the concept,
generate a first version,
explain every line,
customize it into your own style.
6. Topic 2: Sacred Geometry
Sacred geometry is the use of repeated geometric forms that appear in nature, art, architecture, and spiritual symbolism.

Examples:

Flower of Life,
Metatron’s Cube,
Golden Ratio,
Fibonacci spiral,
mandalas,
tessellations,
Islamic geometric patterns,
Platonic solids.
Main point:

Repetition, symmetry, and proportion can create beauty from simple rules.

AI accessibility angle:

Ask AI to generate SVG patterns.
Ask it to convert a geometric idea into Processing or p5.js.
Ask it to animate the construction of the pattern step by step.
Possible visuals:

Flower of Life animation
Fibonacci spiral over a nautilus shell or galaxy
Mandala generator
Golden ratio rectangles
7. Sacred Geometry Talking Point
This is where code feels almost magical.

You can start with something simple, like one circle, then repeat it using rotation, symmetry, and spacing. Suddenly you get patterns that look ancient, spiritual, futuristic, or architectural.

AI helps because you can describe the pattern in human language:

“Make a mandala from rotating circles and triangles, with each layer pulsing slowly.”

Then the code becomes a bridge between imagination and geometry.

8. Topic 3: Gargantua from Interstellar
Gargantua is the black hole from Interstellar.

Why it’s cool:

It was based on real physics.
The visuals involved gravitational lensing.
Light bends around the black hole.
The accretion disk appears warped above and below because of extreme gravity.
Main point:

Scientific equations can create cinematic art.

AI accessibility angle:

You probably cannot casually write a physically accurate black hole renderer from scratch.
But AI can help you understand the approximation.
You can make simplified versions:
warped rings,
glowing accretion disk,
lensing distortion,
shader-based black hole visuals.
Possible demo:

A 2D animated black hole with a glowing disk
A shader that bends background stars around a center point
A “fake but cool” Gargantua-inspired visual
Important framing:

This is not about perfectly simulating astrophysics. It’s about using code to get closer to an idea that used to require a whole VFX team.

9. Gargantua Talking Point
The black hole in Interstellar is a great example because it combines:

math,
physics,
art direction,
cinema,
code.
That is the sweet spot.

AI can help someone who is not a physicist ask:

“How would I fake gravitational lensing visually in JavaScript?”

And suddenly a huge concept becomes something you can experiment with.

10. Topic 4: Music and Audio Visualizers
Audio visualization turns sound into motion.

Examples:

waveform visualizers,
frequency bars,
circular spectrum analyzers,
particles reacting to bass,
music-driven shaders,
live VJ visuals.
Main point:

Music already has structure. Code lets us see that structure.

AI accessibility angle:

AI can help access microphone input.
AI can explain FFT/audio frequency analysis.
AI can help map bass, mids, and treble to color, size, speed, or shape.
Possible demo:

Upload a song and show bars responding to frequencies.
Microphone-reactive particle system.
Bass pulse controlling sacred geometry.
Fractal that changes with audio amplitude.
11. Music Visualizer Talking Point
This is one of the easiest ways to make code feel alive.

Instead of drawing something static, the art responds to sound.

The cool part is that you can map audio data to almost anything:

bass controls scale,
vocals control color,
treble controls particle speed,
rhythm controls rotation.
AI helps because it can explain complicated terms like FFT and then give you a working starting point.

12. “AI Slop” vs “AI as a Creative Tool”
Make this a clear comparison slide.

AI Slop	AI as Creative Coding Assistant
“Make me a cool image”	“Help me build a visual system”
Passive prompting	Active iteration
Generic style	Personal direction
Disposable output	Learnable process
AI makes the thing	AI helps me make the thing
Key line:

The difference is intention. Are you outsourcing taste, or are you using AI to learn and build?

13. The New Creative Workflow
A practical workflow:

Idea
“I want a cosmic mandala that reacts to music.”

Ask AI for concepts
“What math could create this?”

Generate starter code
“Make this in p5.js.”

Modify visually
“Make it darker, slower, more symmetrical.”

Learn the code
“Explain each function.”

Personalize
Add your colors, references, music, timing, symbols, glitches, etc.

Export/share
Turn it into a video, website, projection, or live performance.

14. Tools to Mention
Beginner-friendly:

p5.js — great for browser-based creative coding
Processing — classic creative coding environment
TouchDesigner — node-based visual programming for live visuals
Hydra — live-coded visuals
Three.js — 3D web graphics
Blender + Python — procedural 3D art
ShaderToy / GLSL — advanced visual effects
Sonic Pi / TidalCycles — code-based music
AI-assisted tools:

ChatGPT / Copilot for code help
Cursor or VS Code with AI
Runway, ComfyUI, etc. if discussing visual workflows
Suno/Udio only if you want to touch on music generation, but maybe keep focus on visualizing sound rather than generating music
